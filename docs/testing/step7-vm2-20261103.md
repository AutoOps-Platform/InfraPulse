## 5. Integration fix và xác minh source

**TLS self-monitoring mismatch:** cấu hình base scrape HTTP `ingest:8000`, còn Agent TLS overlay đổi ASGI listener sang HTTPS. Bước7 bổ sung mount verified TLS config + public CA trong [TLS overlay](<../../deploy/compose/compose.agent-tls.yaml>), [renderer stdlib](<../../deploy/scripts/render-prometheus-tls.py>) theo DNS SAN thực, và biến mẫu trong [dotenv template](<../../.env.example>). HTTP base, API/Gateway nghiệp vụ, profile và dashboard queries không bị đổi.

[Regression renderer](<../../deploy/tests/test_prometheus_tls_renderer.py>): watched RED khi chưa có renderer; thêm case private umask077 watched RED vì config600 không đọc được bởi Prometheus UID; sửa file config PUBLIC0644 mà không nới parent private. Final4/4 trên Linux non-root container, network-none/read-only/cap-drop. Bao gồm reject injection và không overwrite operator file. Actual vm-2 verified HTTPS scrape `up=1`.

Fresh local App frontend/backend build exit0; runtime/ops images được build hiện tại rồi transfer, archive/config/layer-chain hash được kiểm sau load. Một lệnh ops ban đầu bị CLI từ chối `run --no-build` **trước khi chạy job**; đã sửa invocation thành supported `run --pull never`, rồi ba jobs mới thành công. GitHub release fetch có403 tạm thời; verified HTTPS200 official release-page hash probe và committed prior provenance cung cấp cùng digest; archive/executable đều match, không giảm TLS/checksum verification.
